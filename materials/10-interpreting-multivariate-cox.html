Much the same as with a single continuous predictor, there are a few key values we can focus on when evaluating and reporting a more complex Cox regression model:

  • hazard ratios (based on our coefficients)
  • global significance tests (specifically, the likelihood ratio test)
  • concordance
  • individual significance tests

We may also want to:

  • make predictions using our model
  • visualise our model

All of these are discussed in this chapter. Throughout, we’ll be using the model we fitted last chapter; rerun this code if the model is not already in your environment:

We already have some practice interpreting the hazard ratio for a continuous predictor such as age, from a previous chapter.

10.2.1 Hazard ratios for categorical predictors

For our binary predictors surgery and weekend_admission, the 0 group will be chosen as our reference.

This means that our hazard ratios compare the hazard for the group coded 1, relative to the group 0 baseline.

For surgery we see a hazard ratio of 0.9489. If we use the formula I previously showed, that tells us that patients who receive surgery have a 5.11% lower hazard of experiencing the event. Since the event is being discharged, this means that they typically stay longer.

For weekend_admission, we see a hazard ratio of 0.7986, corresponding to a 20.14% reduction in hazard for those admitted on a weekend. In other words, being admitted to hospital on a weekend appears to make for a longer time-to-discharge.

10.2.2 Hazard ratios for interaction effects

The interpretation of hazard ratios for interactions is a little more complex, so bear with me here!

Firstly, we can calculate from the age hazard ratio that there is a 4.88% decrease in the hazard for each unit increase in the predictor. In other words, for each year older a patient is, there is a 4.88% decrease in their chance of being discharged at any given point in time.

So how do we now interpret the extra interaction hazard ratio?

Our model has estimated a hazard ratio of 0.9931 for the interaction. This corresponds to a 0.69% decrease in hazard.

This ratio/percentage describes how the effect of age on the hazard changes when we move between the non-surgical (baseline) and surgical groups.

In other words, for each one-year increase in age, the hazard ratio for age is 0.9931 times as large among patients who had surgery, compared with those who did not.

So, the effect of being older is stronger in the surgical group than the non-surgical group.

Warning

Note: this is not the same as saying that surgery reduces the hazard by 0.69 - this would be the main effect of surgery, which we have already calculated.

This is a common mistake with interaction terms!

We get a \(\chi^2\) statistic of 85.4, with an associated p-value of 1.24^{-17}.

This implies that our model is very significant over the null, i.e., our data are very unlikely to have occurred by random chance.

10.4 Concordance

From our summary, we can also see a concordance of 0.695, which corresponds to an accuracy of 69.5%.

In other words, for all possible pairwise patient-patient comparisons across the dataset, our model correctly predicted which one of them “should” have been discharged first 69.5% of the time.

This is a relatively high number, without being unreasonably or suspiciously large, which is promising.

10.6 Making predictions

You can predict different things:

  • Risk score, representing relative hazard compared to the reference group
  • Survival probability for specific new data values
  • Survival curves for specific new data points

Let’s imagine we have three new patients that we want to make predictions for, using our existing model. We know their values for each of the three predictor variables that are included in their model, and we’d like to know how this affects their chances of being discharged.

Age Surgery Weekend admission
50 1 1
70 1 0
90 0 1

First, we’re going to generate an object in our environment that contains these data, like so:

  • R
new_subjects <- data.frame(age = c(50, 70, 90),
                           surgery = c(1, 1, 0),
                           weekend_admission = c(1, 0, 1))

10.6.1 Relative risk scores

One thing we can obtain using these three new imaginary patients is something called a relative risk score for each of them.

  • R

To do this, we use the predict function with the optional type argument set to "risk":

risk_preds <- predict(cox_hosp_int, newdata = new_subjects, type = "risk")
risk_preds
        1         2         3 
0.9961297 0.3999402 0.2004948

What do these numbers actually mean?

These behave a little bit like hazard ratios, comparing each imaginary patient to the baseline hazard estimated by our model.

Tip

For a reminder of how baseline hazard works, you may wish to return to the slides from the second lecture of the course.

So, if we got a relative risk score of exactly 1, this would imply that the combination of predictor values corresponds to the model’s baseline hazard.

If we get relative risk scores > 1, then the hazard is increased; scores < 1 imply that the hazard is decreased. (Note: in this case, increasing hazard is a good thing, because it means the patient is probably getting discharged quicker!)

In this case, all three of our patients are worse off than the baseline hazard to different degrees, but things look much less optimistic for our 90-year-old than our 50-year-old.

10.6.2 Survival probabilities

Another useful question we can ask is: “for an individual with certain values of the predictor variables, what’s the probability that they haven’t experienced the event by a particular time?”

In other words: we can predict the survival probability of an imaginary individual after a specific length of study duration.

  • R

For this, we need a function called predictSurvProb from our new pec package.

Make sure you’ve installed and loaded the package (see the top of this chapter for the code to do this if you need it).

The first step we need to follow is actually quickly refitting our model with an extra argument: x = TRUE. All this does is include the original dataset inside the model object that is created.

Then,

cox_hosp_int2 <- coxph(Surv(time, discharged) ~ age * surgery + weekend_admission,
                       data = hospital_stays,
                       x = TRUE)

Then, we input our model, our set of imaginary patients, and a vector (of any length we want) of times that we’d like to make predictions for.

predictSurvProb(object = cox_hosp_int2,                  
                newdata = new_subjects,                  
                times = c(20, 40, 60, 100))

Each row of the resulting object corresponds to one of our imaginary patients, and each column to one of our time points.

For example, row 1 corresponds to our 50-year-old. At 20 days in, the probability of that patient remaining in hospital (“surviving”, i.e., not having been discharged) is around 12%. By 40 days, it’s dropped to 0.2%.

Meanwhile, in row 3, we have our 90-year-old. Even by 60 days, they still have a 31% chance of remaining in hospital without discharge.

Warning

Note that in our 4th column, we get no predicted survival probabilities. That’s because the value we entered, 100 days, goes beyond the length of the study.

What are we actually visualising here?

Well, these are estimates of the underlying “true” survival curve, for each set of predictor values that we fed into the function.

For example, if we had a dataset consisting entirely of 50-year-olds who received surgery and were admitted on a weekend, we might expect the survival curve to look something like the red curve above (assuming that the model we’ve fitted is accurate to reality).

NoteWhere are the censoring events coming from?

In the curves above, there are several + signs indicating censoring events.

But of course, we’re dealing with hypothetical survival curves here, based on new values of the predictors - so how can there be censoring?

Well, it’s because we’re still basing our estimated curves on a model that was generated from a real dataset, and that dataset did contain censoring.

Another way of thinking about what we’ve done here is that for each of the three curves produced above, we’ve taken the original 210 patients and “adjusted” all of their values to match one row of our new_subjects dataframe.

But of those 210 patients, 21 were censored, and so that censoring carries over into each of the new curves we produce.

10.8 Summary

While adding additional terms to the model doesn’t make it much harder to fit the model itself, it does mean a more lengthy assumption-checking and interpretation procedure, and also makes it a little harder to visualise.

However, it comes with the added benefit of being able to make more accurate predictions, and being able to examine potential interaction effects in the time-to-event dataset.

TipKey Points
  • Fitting Cox regression models with 2+ predictors (including interactions) follows the same simple syntax as fitting linear models with multiple predictors
  • Assumptions of proportional hazards and linearity are checked for each predictor individually/one by one, even when there are multiple predictors
  • We can use concordance and the global likelihood ratio test to evaluate and interpret our model as a whole, and use the model for making predictions about new data points
  • We can use individual p-values and hazard ratios to interpret individual predictors, if we are curious about the mechanisms driving “survival”
